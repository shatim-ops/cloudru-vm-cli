Дефект не из диффа #89, но на денежных путях и противоречит `internal/mcp/server.go:5-7`.
3. **[medium] `k8s_add_nodepool` без группы безопасности в зоне отправляет пул без `securityGroupId`** (`internal/tools/tools_k8s.go:486-496`; этапы 2–3, спецификация mk8s: поле опционально, API примет).
