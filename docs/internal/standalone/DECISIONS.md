## Решения после v1.0.0-rc.1 (15.10.2026)

| # | Вопрос | Решение | Почему |
|---|---|---|---|
| D9 | `confirmation_required` в MCP: `isError: true` или `false` | **Оставить `isError: true`** до v2 | Клиент, различающий исход только по `isError`, при `false` принял бы превью платного действия за выполненное; ложная «ошибка» лишь заставит повторить вызов. Внутренний `image-factory/go/cmd/mcpcall` (проверено по коду) сначала ставит код 1 по `isError`, затем код 3 по `status == "confirmation_required"` — работает при любом значении флага. Клиентам рекомендуется смотреть на `status` (docs/mcp.md) |
| D2 | Имя | **`evo`**, репозиторий `shatim-ops/evo-cli` (переименован 15.10.2026). `cloudru-vm` — alias и `./cmd/cloudru-vm` до v1.1 | Подтверждено владельцем. `./cmd/cloudru-vm` сохранён, потому что сборочная система собирает движок из исходников этой командой |
